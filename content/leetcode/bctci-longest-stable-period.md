# Longest Stable Period

Return the length of the longest contiguous part of `temperatures` whose maximum minus minimum is at most `t`.

## Constraints

- 2 <= temperatures.length <= 100,000.
- Each temperature is between -100 and 100.
- 0 <= t <= 200.


## Examples

### Example 1

```text
Input: [[3, 1, 6, 2], 3]
Output: 2
```

### Example 2

```text
Input: [[-4, -1], 3]
Output: 2
```
