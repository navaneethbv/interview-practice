# Magnetic Force Between Two Balls

Place m balls in distinct baskets at the given positions on a number line.
Maximize the minimum distance between any two placed balls and return that distance.

## Constraints

- `2 <= m <= position.length <= 100000`.
- Positions are distinct integers from 1 to 1000000000.

## Examples

### Example 1

```text
Input: position = [1, 3, 6, 10], m = 3
Output: 4
Explanation: Using positions 1,6,10 gives minimum distance 4.
```

### Example 2

```text
Input: position = [1, 100], m = 2
Output: 99
Explanation: Both baskets must be used.
```
