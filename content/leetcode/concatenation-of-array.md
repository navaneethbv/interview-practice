# Concatenation of Array

Return a new array consisting of all entries of `nums` followed by the same entries again.

## Examples

### Example 1

```text
Input: nums = [1, 2, 1]
Output: [1, 2, 1, 1, 2, 1]
Explanation: Append a second copy in the same order.
```

### Example 2

```text
Input: nums = [5]
Output: [5, 5]
Explanation: A single entry appears twice.
```

## Constraints

- 1 <= nums.length <= 1,000
- 1 <= nums[i] <= 1,000
