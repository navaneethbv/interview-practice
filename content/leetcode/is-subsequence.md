# Is Subsequence

Return whether all characters of `s` can be selected from `t` in order, possibly skipping other characters.

## Examples

### Example 1

```text
Input: s = "abc", t = "ahbgdc"
Output: true
Explanation: Select a, then b, then c.
```

### Example 2

```text
Input: s = "axc", t = "ahbgdc"
Output: false
Explanation: There is no x to select.
```

## Constraints

- 0 <= s.length <= 100
- 0 <= t.length <= 10,000
- Both strings contain lowercase English letters.
