# Permutation Sequence

List all permutations of digits 1 through n in lexicographic order.
Return the kth permutation as a string, where k is one-based.

## Examples

### Example 1

```text
Input: n = 3, k = 3
Output: "213"
Explanation: The order begins 123, 132, 213.
```

### Example 2

```text
Input: n = 3, k = 6
Output: "321"
Explanation: This is the final permutation of three digits.
```

## Constraints

- 1 <= n <= 9
- 1 <= k <= n!
