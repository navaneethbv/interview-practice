# 3-Sum

Return whether three distinct indices of `arr` have values whose sum is `w`.
Repeated values may be used when they come from different positions.

## Constraints

- 0 <= arr.length <= 1,000.
- Values and w are between -10,000,000 and 10,000,000.


## Examples

### Example 1

```text
Input: [[2, 2, -1, 8], 3]
Output: true
```

### Example 2

```text
Input: [[2, 0, 1], 4]
Output: false
```
