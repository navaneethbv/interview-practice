# Third Maximum Number

Return the third largest distinct value in `nums`. If there are fewer than three distinct values, return the largest.

## Constraints

- 1 <= nums.length <= 10^4
- -2^31 <= nums[i] <= 2^31 - 1

## Examples

### Example 1

```text
Input: nums = [3, 2, 1]
Output: 1
Explanation: The third distinct maximum is 1.
```

### Example 2

```text
Input: nums = [2, 2, 3, 1]
Output: 1
Explanation: Distinct values are 3, 2 and 1; duplicates count once.
```
