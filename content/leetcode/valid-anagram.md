# Valid Anagram

Determine whether `t` can be obtained by rearranging all characters of `s`.
Each occurrence must be used exactly once.

## Constraints

- `1 <= s.length, t.length <= 50000`.
- Both strings contain lowercase English letters.

## Examples

### Example 1

```text
Input: s = "silent", t = "listen"
Output: true
Explanation: Both words contain the same character counts.
```

### Example 2

```text
Input: s = "aab", t = "abb"
Output: false
Explanation: The number of a characters differs.
```
