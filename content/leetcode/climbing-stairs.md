# Climbing Stairs

A staircase has `n` steps.
Each move climbs either one or two steps.
Return the number of different ordered sequences of moves that land exactly on the top.

## Examples

### Example 1

```text
Input: n = 4
Output: 5
Explanation: The sequences are 1111, 112, 121, 211, and 22.
```

### Example 2

```text
Input: n = 1
Output: 1
Explanation: There is only the single one-step move.
```

## Constraints

- 1 <= n <= 45
