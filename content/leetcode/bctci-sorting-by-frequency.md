# Sorting by Frequency

Return the distinct letters of `word` ordered from most to least frequent, breaking ties alphabetically.

## Examples

### Example 1

```text
Input: word = "aabbbcccc"
Output: ["c", "b", "a"]
```

### Example 2

```text
Input: word = "abc"
Output: ["a", "b", "c"]
```

## Constraints

- `0 <= word.length <= 10^5`
- `word` contains lowercase letters only.
