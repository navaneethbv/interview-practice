# Is Unique

Return `true` when every character in `s` appears at most once.
Return `false` as soon as a repeated character is found.
Treat characters as the exact Unicode characters supplied by the caller.

## Examples

### Example 1

```text
Input: s = "lamp"
Output: true
```

### Example 2

```text
Input: s = "letter"
Output: false
```

## Constraints

- `0 <= s.length <= 100,000`
- The input may contain letters, digits, spaces, and punctuation.
