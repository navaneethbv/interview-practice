# Multiply Strings

Multiply two nonnegative integers represented as decimal strings.
Return the product as a decimal string.
Do not convert either entire input into an integer or use a big-integer library.

## Examples

### Example 1

```text
Input: num1 = "12", num2 = "34"
Output: "408"
Explanation: Twelve times thirty-four equals 408.
```

### Example 2

```text
Input: num1 = "0", num2 = "999"
Output: "0"
Explanation: Multiplication by zero gives zero.
```

## Constraints

- 1 <= num1.length, num2.length <= 200
- Inputs contain decimal digits without leading zeros except for 0.
