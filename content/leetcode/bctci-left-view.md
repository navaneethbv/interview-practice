# Left View

Return the left view of a binary tree: the value of the first node on each level, from top to bottom.

## Examples

### Example 1

```text
Input: root = [1, 2, 3, null, 5, null, 6, null, null, null, 7]
Output: [1, 2, 5, 7]
```

### Example 2

```text
Input: root = []
Output: []
```

## Constraints

- `0 <= number of nodes <= 10^5`
