# Powers Mod M

Given `a > 1`, `p >= 0`, and `m > 1`, return `a^p mod m` without ever holding a value much larger than `m`.

## Examples

### Example 1

```text
Input: a = 2, p = 5, m = 30
Output: 2
```

### Example 2

```text
Input: a = 123456789, p = 987654321, m = 1000000007
Output: 652541198
```

## Constraints

- `1 < a <= 10^9`
- `0 <= p <= 10^9`
- `1 < m <= 10^9`
