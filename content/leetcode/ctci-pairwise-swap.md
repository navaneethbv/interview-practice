# Pairwise Swap

Swap every even bit of a 32-bit integer with the odd bit next to it: bit 0 with bit 1, bit 2 with bit 3, and so on.
Use as few operations as possible.
The input and output are 32-bit two's complement integers, so the result may be negative.

## Examples

### Example 1

```text
Input: n = 10
Output: 5
Explanation: 1010 becomes 0101.
```

### Example 2

```text
Input: n = 1
Output: 2
```

## Constraints

- `-2^31 <= n <= 2^31 - 1`
