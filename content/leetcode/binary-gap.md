# Binary Gap

Consider neighboring set bits in the binary representation of n.
Return the largest distance between their bit positions, or 0 if there are fewer than two set bits.

## Examples

### Example 1

```text
Input: n = 22
Output: 2
Explanation: Binary 10110 has neighboring set-bit distances 2 and 1.
```

### Example 2

```text
Input: n = 8
Output: 0
Explanation: Binary 1000 contains only one set bit.
```

## Constraints

- 1 <= n <= 10^9
