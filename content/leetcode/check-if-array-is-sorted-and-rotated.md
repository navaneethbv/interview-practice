# Check if Array Is Sorted and Rotated

Return whether nums can be obtained by rotating a nondecreasing array by any number of positions, including zero.
Duplicate values are allowed.

## Examples

### Example 1

```text
Input: nums = [3, 4, 5, 1, 2]
Output: true
Explanation: Rotate the sorted order 1,2,3,4,5 by three positions.
```

### Example 2

```text
Input: nums = [2, 1, 3, 4]
Output: false
Explanation: No single rotation places these values in sorted order.
```

## Constraints

- 1 <= nums.length <= 100.
- 1 <= nums[i] <= 100.
