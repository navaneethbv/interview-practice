# Longest Valid Parentheses

Return the length of the longest contiguous substring that forms a balanced parentheses sequence.

## Examples

### Example 1

```text
Input: s = ")()())"
Output: 4
Explanation: The substring ()() has length 4.
```

### Example 2

```text
Input: s = "(()"
Output: 2
Explanation: The final two characters form a balanced pair.
```

## Constraints

- 0 <= s.length <= 30,000
- s contains only ( and ).
