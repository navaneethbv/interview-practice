# Sum of Square Numbers

Determine whether nonnegative integers a and b exist with `a*a + b*b == c`.
Zero is allowed for either integer.

## Constraints

- `0 <= c <= 2147483647`.

## Examples

### Example 1

```text
Input: c = 13
Output: true
Explanation: 2 squared plus 3 squared is 13.
```

### Example 2

```text
Input: c = 7
Output: false
Explanation: No pair of integer squares sums to 7.
```
