# 2-Sum

Given an array sorted in ascending order, return whether two different indices `i` and `j` satisfy `arr[i] + arr[j] == 0`.

## Examples

### Example 1

```text
Input: arr = [-5, -2, -1, 1, 1, 10]
Output: true
```

### Example 2

```text
Input: arr = [-5, -3, -1, 0, 2, 4, 6]
Output: false
```

## Constraints

- `0 <= arr.length <= 10^6`
- `-10^9 <= arr[i] <= 10^9`
