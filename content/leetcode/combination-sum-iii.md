# Combination Sum III

Return all ways to select exactly k distinct numbers from 1 through 9 whose sum is n.
Each number may be used once.
Both combination order and order inside each combination are unrestricted.

## Examples

### Example 1

```text
Input: k = 3, n = 7
Output: [[1, 2, 4]]
Explanation: Only 1 + 2 + 4 gives 7 using three distinct digits.
```

### Example 2

```text
Input: k = 3, n = 9
Output: [[1, 2, 6], [1, 3, 5], [2, 3, 4]]
Explanation: These are the three valid combinations.
```

## Constraints

- 2 <= k <= 9
- 1 <= n <= 60
