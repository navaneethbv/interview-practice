# Base 7

Return the base-7 representation of num using digits 0 through 6.
Use a leading minus sign for a negative number and no unnecessary leading zeros.

## Examples

### Example 1

```text
Input: num = 100
Output: "202"
Explanation: 100 equals 2 times 49 plus 2.
```

### Example 2

```text
Input: num = -8
Output: "-11"
Explanation: The magnitude 8 equals 7 + 1.
```

## Constraints

- -10000000 <= num <= 10000000.
