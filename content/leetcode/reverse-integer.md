# Reverse Integer

Reverse the decimal digits of signed integer `x`, preserving its sign and discarding leading zeros from the reversed result.
Return 0 if the result is outside the signed 32-bit range.
Solve the problem without storing a 64-bit integer.

## Examples

### Example 1

```text
Input: x = 120
Output: 21
Explanation: The reversed digits 021 represent 21.
```

### Example 2

```text
Input: x = -407
Output: -704
Explanation: Reverse the digits while keeping the negative sign.
```

## Constraints

- -2^31 <= x <= 2^31 - 1
