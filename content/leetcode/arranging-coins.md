# Arranging Coins

Build a staircase from n coins, where row i needs exactly i coins.
Return the number of complete rows; leftover coins in an incomplete row do not count.

## Examples

### Example 1

```text
Input: n = 8
Output: 3
Explanation: Rows of 1,2,3 use six coins, leaving two toward row 4.
```

### Example 2

```text
Input: n = 10
Output: 4
Explanation: The first four rows use exactly ten coins.
```

## Constraints

- 1 <= n <= 2147483647.
