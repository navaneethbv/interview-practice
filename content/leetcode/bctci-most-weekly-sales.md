# Most Weekly Sales

`sales[i]` is the number of sales on day `i`.
Return the most sales in any 7 consecutive days, or 0 if there are fewer than 7 days.

## Examples

### Example 1

```text
Input: sales = [0, 3, 7, 12, 10, 5, 0, 1, 0, 15, 12, 11, 1]
Output: 44
```

### Example 2

```text
Input: sales = [0, 3, 7, 12]
Output: 0
```

## Constraints

- `0 <= sales.length <= 10^6`
- `0 <= sales[i] < 10^3`
