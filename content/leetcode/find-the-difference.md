# Find the Difference

String `t` was made by shuffling `s` and adding one extra lowercase letter.
Return the added letter.

## Examples

### Example 1

```text
Input: s = "abcd", t = "abcde"
Output: "e"
Explanation: Only e was added.
```

### Example 2

```text
Input: s = "a", t = "aa"
Output: "a"
Explanation: The extra occurrence is another a.
```

## Constraints

- 0 <= s.length <= 1,000
- t.length == s.length + 1
- Both strings contain lowercase English letters and satisfy the stated relationship.
