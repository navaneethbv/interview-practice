# Sort an Array

Return the integers sorted in ascending order.
Use an O(n log n) algorithm without calling a built-in sort routine.

## Examples

### Example 1

```text
Input: nums = [5, 2, 3, 1]
Output: [1, 2, 3, 5]
Explanation: Arrange the entries from smallest to largest.
```

### Example 2

```text
Input: nums = [5, 1, 1, 2, 0, 0]
Output: [0, 0, 1, 1, 2, 5]
Explanation: Retain all repeated occurrences.
```

## Constraints

- 1 <= nums.length <= 50,000
- -50,000 <= nums[i] <= 50,000
