# Add Binary

Add binary strings `a` and `b` and return their sum as a binary string without unnecessary leading zeros.

## Examples

### Example 1

```text
Input: a = "11", b = "1"
Output: "100"
Explanation: Three plus one equals four.
```

### Example 2

```text
Input: a = "101", b = "11"
Output: "1000"
Explanation: Five plus three equals eight.
```

## Constraints

- 1 <= a.length, b.length <= 10,000
- The strings contain only 0 and 1 and have no leading zeros unless equal to 0.
