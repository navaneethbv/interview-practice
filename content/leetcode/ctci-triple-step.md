# Triple Step

A child runs up a staircase of `n` steps, taking 1, 2, or 3 steps at a time.
Return the number of distinct ways to reach the top, modulo `1,000,000,007`.
There is one way to climb zero steps.

## Examples

### Example 1

```text
Input: n = 3
Output: 4
Explanation: 1+1+1, 1+2, 2+1, and 3.
```

### Example 2

```text
Input: n = 0
Output: 1
```

## Constraints

- `0 <= n <= 100,000`
