# Concatenation of Consecutive Binary Numbers

Write the binary representations of 1 through n consecutively without separators.
Interpret the resulting bit string as an integer and return it modulo 1,000,000,007.

## Examples

### Example 1

```text
Input: n = 3
Output: 27
Explanation: Concatenating 1, 10, and 11 gives binary 11011.
```

### Example 2

```text
Input: n = 1
Output: 1
Explanation: Only the representation of 1 is present.
```

## Constraints

- 1 <= n <= 100,000
