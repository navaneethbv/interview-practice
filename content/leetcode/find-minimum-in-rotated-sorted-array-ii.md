# Find Minimum in Rotated Sorted Array II

A nondecreasing array, possibly containing duplicates, was cyclically rotated an unknown number of positions.
Return its smallest value.

## Examples

### Example 1

```text
Input: nums = [2, 2, 2, 0, 1]
Output: 0
Explanation: Zero is the smallest entry.
```

### Example 2

```text
Input: nums = [1, 1, 1]
Output: 1
Explanation: All entries have the same value.
```

## Constraints

- 1 <= nums.length <= 5000
- -5000 <= nums[i] <= 5000
- nums is a rotation of a nondecreasing array.
