# Generate Parentheses

Generate every balanced string containing exactly n opening parentheses and n closing parentheses.
A string is balanced when every prefix has at least as many opening as closing parentheses, and the total counts match.
Return each string once, in any order.

## Examples

### Example 1

```text
Input: n = 1
Output: ["()"]
Explanation: Only one arrangement is balanced.
```

### Example 2

```text
Input: n = 2
Output: ["(())", "()()"]
Explanation: The two pairs can be nested or adjacent.
```

## Constraints

- 1 <= n <= 8.
