# Intersection of Two Arrays

Return the distinct values that appear in both arrays.
Include each shared value once, in any order.

## Examples

### Example 1

```text
Input: nums1 = [1, 2, 2, 3], nums2 = [2, 3, 4]
Output: [2, 3]
Explanation: 2 and 3 occur in both inputs.
```

### Example 2

```text
Input: nums1 = [1], nums2 = [2]
Output: []
Explanation: The inputs share no value.
```

## Constraints

- 1 <= nums1.length, nums2.length <= 1000.
- 0 <= values <= 1000.
