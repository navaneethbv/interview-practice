# Check if Binary String Has at Most One Segment of Ones

Return whether all 1 characters in s belong to one contiguous segment.

## Examples

### Example 1

```text
Input: s = "1100"
Output: true
Explanation: Both 1 characters belong to the initial segment.
```

### Example 2

```text
Input: s = "1001"
Output: false
Explanation: Zeros separate the two 1 segments.
```

## Constraints

- 1 <= s.length <= 100
- s is binary and starts with 1.
