# Find the Index of the First Occurrence in a String

Return the starting index of the earliest occurrence of needle as a contiguous substring of haystack.
Return -1 if it never occurs.
Indices start at zero.

## Examples

### Example 1

```text
Input: haystack = "bananana", needle = "nana"
Output: 2
Explanation: The first match starts at index 2.
```

### Example 2

```text
Input: haystack = "hello", needle = "world"
Output: -1
Explanation: There is no matching substring.
```

## Constraints

- 1 <= haystack.length, needle.length <= 10000.
- Both strings contain lowercase English letters.
