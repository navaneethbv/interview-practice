# Longest Good Day Streak

A bad day has fewer than 10 sales and a good day has at least 10.
Return the largest number of consecutive good days.

## Examples

### Example 1

```text
Input: sales = [0, 14, 7, 12, 10, 20]
Output: 3
```

### Example 2

```text
Input: sales = [5, 5, 5]
Output: 0
```

## Constraints

- `0 <= sales.length <= 10^5`
- `0 <= sales[i] <= 10^3`
