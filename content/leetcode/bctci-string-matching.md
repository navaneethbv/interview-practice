# String Matching

Return the first index at which string `t` occurs in string `s`, or `-1` if it does not occur.
An empty `t` occurs at index 0, even when `s` is empty.

## Examples

### Example 1

```text
Input: s = "hello world", t = "world"
Output: 6
```

### Example 2

```text
Input: s = "needle in a haystack", t = "not"
Output: -1
```

## Constraints

- `0 <= s.length, t.length <= 10^5`
- Strings contain printable ASCII characters.
