# Dutch Flag Problem

`arr` contains only the characters `R`, `W`, and `B`.
Sort it in place so that all `R` come first, then all `W`, then all `B`, in one pass with O(1) extra space.

## Examples

### Example 1

```text
Input: arr = ["R", "W", "B", "B", "W", "R", "W"]
Output: ["R", "R", "W", "W", "W", "B", "B"]
```

### Example 2

```text
Input: arr = ["B", "R"]
Output: ["R", "B"]
```

## Constraints

- `0 <= arr.length <= 10^6`
