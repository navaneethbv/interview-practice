# Enduring Best Seller Streak

`bestSeller[i]` is the best-selling title on day `i`.
Return whether some `k` consecutive days all have the same best seller.

## Examples

### Example 1

```text
Input: bestSeller = ["book3", "book1", "book3", "book3", "book2"], k = 2
Output: true
```

### Example 2

```text
Input: bestSeller = ["book1", "book2", "book1"], k = 2
Output: false
```

## Constraints

- `1 <= k <= bestSeller.length <= 10^6`
