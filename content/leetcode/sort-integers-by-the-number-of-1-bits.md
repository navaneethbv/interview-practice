# Sort Integers by The Number of 1 Bits

Sort the integers by increasing number of set bits in their binary representations.
Break ties by increasing numeric value and retain duplicate occurrences.

## Examples

### Example 1

```text
Input: arr = [0, 1, 2, 3, 4]
Output: [0, 1, 2, 4, 3]
Explanation: The powers of two have one set bit; 3 has two.
```

### Example 2

```text
Input: arr = [7, 3, 1]
Output: [1, 3, 7]
Explanation: The values have one, two, and three set bits.
```

## Constraints

- 1 <= arr.length <= 500
- 0 <= arr[i] <= 10,000
