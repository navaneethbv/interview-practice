# Next Greater Element III

Rearrange exactly the decimal digits of n to form the smallest integer strictly larger than n.
Return -1 when no larger arrangement exists or when the answer exceeds the signed 32-bit maximum.

## Examples

### Example 1

```text
Input: n = 1243
Output: 1324
Explanation: 1324 is the next digit permutation in increasing order.
```

### Example 2

```text
Input: n = 321
Output: -1
Explanation: The digits are already in descending order.
```

## Constraints

- 1 <= n <= 2147483647.
