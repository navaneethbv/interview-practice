# Count Substrings Without Letter

Count nonempty contiguous substrings of `s` that contain no `a`.
Count occurrences at different positions separately.
Use a 64-bit result in Java.

## Constraints

- 0 <= s.length <= 100,000.
- s contains lowercase English letters.


## Examples

### Example 1

```text
Input: ["bbac"]
Output: 4
```

### Example 2

```text
Input: ["aaa"]
Output: 0
```
