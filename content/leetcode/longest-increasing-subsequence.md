# Longest Increasing Subsequence

Return the greatest length of a strictly increasing subsequence of `nums`.
You may remove entries, but the remaining entries must preserve their original order.

## Examples

### Example 1

```text
Input: nums = [5, 1, 4, 2, 3]
Output: 3
Explanation: The subsequence [1, 2, 3] has length 3.
```

### Example 2

```text
Input: nums = [7, 7, 7]
Output: 1
Explanation: Equal entries cannot extend a strictly increasing subsequence.
```

## Constraints

- 1 <= nums.length <= 2,500
- -10,000 <= nums[i] <= 10,000
