# Add Two Numbers II

Two nonempty linked lists represent nonnegative integers with the most significant digit first.
Return a new list representing their sum in the same order.
Each node stores a decimal digit; numbers have no leading zero unless the entire number is zero.

## Constraints

- Each input has 1 to 100 nodes.
- Node values range from 0 to 9.

## Examples

### Example 1

```text
Input: l1 = [1, 2, 3], l2 = [7, 7]
Output: [2, 0, 0]
Explanation: 123 + 77 = 200.
```

### Example 2

```text
Input: l1 = [0], l2 = [0]
Output: [0]
Explanation: Zero plus zero is zero.
```
