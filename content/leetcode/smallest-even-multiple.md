# Smallest Even Multiple

Return the smallest positive integer that is divisible by both n and 2.

## Examples

### Example 1

```text
Input: n = 7
Output: 14
Explanation: The first multiple of 7 that is even is 14.
```

### Example 2

```text
Input: n = 12
Output: 12
Explanation: The number 12 is already even.
```

## Constraints

- 1 <= n <= 150
