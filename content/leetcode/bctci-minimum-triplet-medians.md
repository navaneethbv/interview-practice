# Minimum Triplet Medians

`arr` holds distinct integers and its length is a multiple of 3.
Split it into triplets to minimize the sum of the triplets' medians, and return that sum.

## Examples

### Example 1

```text
Input: arr = [6, 5, 8, 2, 1, 9]
Output: 8
```

### Example 2

```text
Input: arr = [6, 5, 8, 2, 1, 9, 12, 15, 14]
Output: 17
```

## Constraints

- `3 <= arr.length < 10^5`
- `1 <= arr[i] <= 10^9`
