# Valid Palindrome II

Return whether `s` can become a palindrome after deleting at most one character.
Deleting no characters is allowed.

## Examples

### Example 1

```text
Input: s = "abca"
Output: true
Explanation: Delete b or c to produce a palindrome.
```

### Example 2

```text
Input: s = "abc"
Output: false
Explanation: One deletion cannot make the ends match throughout.
```

## Constraints

- 1 <= s.length <= 100,000
- s contains lowercase English letters.
