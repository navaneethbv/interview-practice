## Intuition

An IPv4 address has exactly four decimal parts.
Backtracking tries one to three digits per part and rejects leading zeroes and values above 255.

## Brute force

Trying every three-dot placement gives O(n cubed) possible splits.
Validation after each split still wastes placements that cannot leave enough digits for four parts.

## Approach

1. Track the next string position and chosen parts.
2. Prune when remaining digits cannot fill the remaining parts.
3. Try lengths one through three, validate the segment, and recurse.
4. Add a joined address only after four parts consume the entire string.

## Walkthrough

Example 1:

For 25525511135, one valid split is 255,255,11,135, producing 255.255.11.135.
Another is 255,255,111,35, producing 255.255.111.35.
Both use four valid parts and consume all eleven digits.

## Complexity

At most three choices are made for each of four positions, so the bounded search is O(3 to the fourth) plus output construction.
More generally the recursion uses O(n) path and call-stack space, and output uses O(Rn) for R addresses.
Python and Java both copy segment strings while building results.

## Edge cases

0000 produces four zero parts because single zeroes are valid.
A multi-digit part beginning with zero is invalid.
Strings shorter than four or longer than twelve digits are pruned.

## Common mistakes

Do not accept 00 or 025 as a segment.
Do not stop after finding four valid parts if characters remain.
Keep the address order generated by the existing reference.

## Language notes

Python joins the current part list.
Java uses String.join and a mutable ArrayList during recursion.
