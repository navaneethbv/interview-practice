# Balanced Partition

`s` is a balanced string of parentheses.
Split it into as many consecutive pieces as possible so that every piece is balanced, and return the number of pieces.

## Examples

### Example 1

```text
Input: s = "((()))(()())()(()(()))"
Output: 4
```

### Example 2

```text
Input: s = ""
Output: 0
```

## Constraints

- `0 <= s.length <= 10^5`
