# Sort Stack

A stack is given as an array listed from bottom to top.
Sort it so that the smallest value is on top, using only one additional stack as temporary storage.
Return the sorted stack, again listed from bottom to top.

## Examples

### Example 1

```text
Input: stack = [3, 1, 4, 2]
Output: [4, 3, 2, 1]
Explanation: The top of the returned stack is 1, the smallest value.
```

### Example 2

```text
Input: stack = [5, 5, 1]
Output: [5, 5, 1]
```

## Constraints

- `0 <= stack.length <= 2,000`
- `-100,000 <= stack[i] <= 100,000`
