# Self-Doubling Sequence

Begin with the sequence [0].
Each round appends a copy of the entire current sequence with 1 added to every copied element.
Return the element at zero-based index `n` in the infinite sequence.

## Constraints

- 0 <= n <= 1,000,000,000.
- Do not construct the full sequence.


## Examples

### Example 1

```text
Input: [5]
Output: 2
```

### Example 2

```text
Input: [15]
Output: 4
```
