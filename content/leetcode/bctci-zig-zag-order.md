# Zig-Zag Order

Return all node values in zig-zag order as one flat list: even-depth levels from left to right and odd-depth levels from right to left, level by level from the top.

## Examples

### Example 1

```text
Input: root = [1, 2, 3, 4, 5, null, 6]
Output: [1, 3, 2, 4, 5, 6]
```

### Example 2

```text
Input: root = []
Output: []
```

## Constraints

- `0 <= number of nodes <= 10^5`
