# Length of Last Word

Return the number of letters in the last word of s.
A word is a maximal consecutive run of non-space characters.
Ignore any spaces after the final word.

## Examples

### Example 1

```text
Input: s = "learn every day  "
Output: 3
Explanation: The last word is day.
```

### Example 2

```text
Input: s = "one"
Output: 3
Explanation: The only word has length 3.
```

## Constraints

- 1 <= s.length <= 10000.
- s contains English letters and spaces, and at least one word.
