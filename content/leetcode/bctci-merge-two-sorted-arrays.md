# Merge Two Sorted Arrays

Given two arrays sorted in ascending order, return a new sorted array containing all of their elements, including duplicates.

## Examples

### Example 1

```text
Input: arr1 = [1, 3, 4, 5], arr2 = [2, 4, 4]
Output: [1, 2, 3, 4, 4, 4, 5]
```

### Example 2

```text
Input: arr1 = [-1], arr2 = []
Output: [-1]
```

## Constraints

- `0 <= arr1.length, arr2.length <= 10^6`
- `-10^9 <= arr1[i], arr2[i] <= 10^9`
