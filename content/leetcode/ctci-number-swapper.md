# Number Swapper

Swap two integers in place without a temporary variable, and return them as `[a, b]` after the swap.

## Examples

### Example 1

```text
Input: a = 3, b = 9
Output: [9, 3]
```

### Example 2

```text
Input: a = -4, b = -4
Output: [-4, -4]
```

## Constraints

- `-2^31 <= a, b <= 2^31 - 1`
