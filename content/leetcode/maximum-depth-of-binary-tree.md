# Maximum Depth of Binary Tree

Return the number of nodes on a longest path from the root down to a leaf.
An empty tree has depth zero.
Trees in the testcase editor use level-order arrays, with `null` for missing children.

## Constraints

- The tree has 0 to 10000 nodes.
- Node values are integers between -100 and 100.

## Examples

### Example 1

```text
Input: root = [8, 3, 10, null, 6]
Output: 3
Explanation: The path 8, 3, 6 contains three nodes.
```

### Example 2

```text
Input: root = []
Output: 0
Explanation: There is no root.
```
