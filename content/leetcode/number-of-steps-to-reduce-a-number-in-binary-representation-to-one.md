# Number of Steps to Reduce a Number in Binary Representation to One

Given a positive integer as binary string s, repeatedly divide it by two when even or add one when odd, stopping at one.
Return the number of operations.

## Constraints

- s has 1 to 500 binary digits and begins with 1.

## Examples

### Example 1

```text
Input: s = "11"
Output: 3
Explanation: Three becomes four, then two, then one.
```

### Example 2

```text
Input: s = "1"
Output: 0
Explanation: The value is already one.
```
