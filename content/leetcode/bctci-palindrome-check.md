# Palindrome Check

Return whether the lowercase string `s` reads the same forward and backward.

## Examples

### Example 1

```text
Input: s = "level"
Output: true
```

### Example 2

```text
Input: s = "hello"
Output: false
```

## Constraints

- `0 <= s.length <= 10^6`
- `s` consists of lowercase English letters.
