# N-Queens II

Count the ways to place n queens on an n by n chessboard so that no two queens share a row, column, or diagonal.
Placements that differ by rotation or reflection count separately.

## Examples

```text
Input: n = 4
Output: 2
Explanation: The four-row board has two valid placements.
```

```text
Input: n = 1
Output: 1
Explanation: The only square holds the only queen.
```

## Constraints

- 1 <= n <= 9
- Return the number of distinct placements, not the boards.
