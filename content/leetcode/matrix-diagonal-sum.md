# Matrix Diagonal Sum

Return the sum of entries on either diagonal of a square matrix.
Count the center only once when the matrix size is odd.

## Examples

### Example 1

```text
Input: mat = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
Output: 25
Explanation: Sum 1, 3, 5, 7, and 9.
```

### Example 2

```text
Input: mat = [[1, 2], [3, 4]]
Output: 10
Explanation: Every cell lies on a diagonal.
```

## Constraints

- 1 <= mat.length == mat[i].length <= 100
- 1 <= mat[i][j] <= 100
