# Minimum Steps to One

Starting from `n`, reach 1 using the fewest operations, where each operation subtracts 1, divides by 2 when divisible, or divides by 3 when divisible.
Return the number of operations.

## Examples

### Example 1

```text
Input: n = 10
Output: 3
Explanation: 10, 9, 3, 1.
```

### Example 2

```text
Input: n = 1
Output: 0
```

## Constraints

- `1 <= n <= 10^6`
