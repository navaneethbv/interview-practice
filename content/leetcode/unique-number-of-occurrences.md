# Unique Number of Occurrences

Count occurrences of each distinct integer.
Return whether no two distinct values have the same occurrence count.

## Examples

### Example 1

```text
Input: arr = [1, 2, 2, 1, 1, 3]
Output: true
Explanation: The three frequencies are 3, 2, and 1.
```

### Example 2

```text
Input: arr = [1, 2]
Output: false
Explanation: Both values occur once.
```

## Constraints

- 1 <= arr.length <= 1,000
- -1,000 <= arr[i] <= 1,000
