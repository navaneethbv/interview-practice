# Minimum Changes To Make Alternating Binary String

Change the fewest characters in binary s so every pair of adjacent characters differs.
A change flips one bit.
Return the minimum number of changes.

## Constraints

- s contains 1 to 10000 binary digits.

## Examples

### Example 1

```text
Input: s = "001"
Output: 1
Explanation: Flipping the first digit gives 101.
```

### Example 2

```text
Input: s = "1010"
Output: 0
Explanation: The string already alternates.
```
