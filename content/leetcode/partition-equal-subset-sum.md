# Partition Equal Subset Sum

Determine whether all entries of `nums` can be divided between two subsets with equal sums.
Use each array entry exactly once.

## Examples

### Example 1

```text
Input: nums = [1, 5, 11, 5]
Output: true
Explanation: Choose [11] and [1,5,5].
```

### Example 2

```text
Input: nums = [1, 2, 5]
Output: false
Explanation: No subset has half the total sum, 4.
```

## Constraints

- 1 <= nums.length <= 200
- 1 <= nums[i] <= 100
