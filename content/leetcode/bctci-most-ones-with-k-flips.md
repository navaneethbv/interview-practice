# Most Ones With K Flips

Return the longest contiguous run of ones obtainable by changing at most `k` zeros to ones in binary array `arr`.
An empty array has answer 0.

## Constraints

- 0 <= arr.length <= 100,000.
- Each entry is 0 or 1; 0 <= k <= arr.length.


## Examples

### Example 1

```text
Input: [[1, 0, 1, 0, 1], 1]
Output: 3
```

### Example 2

```text
Input: [[], 0]
Output: 0
```
