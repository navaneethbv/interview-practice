# Intersection of Three Sorted Arrays

Return the values present in all three arrays, in ascending order.

## Constraints

- Each array contains 1 to 1000 strictly increasing integers.
- Values range from 1 to 2000.

## Examples

### Example 1

```text
Input: arr1 = [1, 2, 4], arr2 = [2, 3, 4], arr3 = [2, 4, 5]
Output: [2, 4]
Explanation: Only 2 and 4 occur in every array.
```

### Example 2

```text
Input: arr1 = [1], arr2 = [2], arr3 = [3]
Output: []
Explanation: There is no common value.
```
