# Number of Squareful Arrays

Count distinct permutations of nums for which each adjacent pair sums to a perfect square.
Permutations that differ only by exchanging equal values count once.

## Constraints

- `1 <= nums.length <= 12`.
- Values range from 0 to 1000000000.

## Examples

### Example 1

```text
Input: nums = [1, 17, 8]
Output: 2
Explanation: The valid orders are 1,8,17 and 17,8,1.
```

### Example 2

```text
Input: nums = [2, 2, 2]
Output: 1
Explanation: The sole distinct ordering has adjacent sums equal to 4.
```
