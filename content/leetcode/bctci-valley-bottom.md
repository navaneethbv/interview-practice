# Valley Bottom

`arr` has distinct values and is valley-shaped: a non-empty strictly decreasing prefix followed by a non-empty strictly increasing suffix.
Return its smallest value in logarithmic time.

## Examples

### Example 1

```text
Input: arr = [6, 5, 4, 7, 9]
Output: 4
```

### Example 2

```text
Input: arr = [7, 6, 5]
Output: 5
```

## Constraints

- `2 <= arr.length <= 10^6`
- `-10^9 <= arr[i] <= 10^9`
