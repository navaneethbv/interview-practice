# BCTCI oracle cases

`bctci_online.json` freezes the 1,470 small-instance cases previously generated by seeds 601 through 608 in `test_bctci_online.py`.
The windows, graphs, time queries, elections, arrays, strings, games, and trees groups retain their original order and inputs.
Tests derive expected results independently through exhaustive enumeration, graph traversal, or state-space search.
The corpus contains inputs only, not reference-generated expected answers.
Freezing it removes runtime pseudo-random generation and keeps failures reproducible across Python versions.

Run `python3 -B scripts/judge/test_bctci_online.py` from the repository root.
Add explicit cases to the relevant group when expanding coverage.
