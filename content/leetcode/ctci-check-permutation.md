# Check Permutation

Return `true` when `first` and `second` contain exactly the same characters with the same multiplicities, regardless of order.
Return `false` when their lengths differ or any character count differs.
Matching is case-sensitive and spaces are significant.

## Examples

### Example 1

```text
Input: first = "earth", second = "heart"
Output: true
```

### Example 2

```text
Input: first = "apple", second = "pearl"
Output: false
```

## Constraints

- `0 <= first.length, second.length <= 100,000`
- The inputs may contain arbitrary Unicode characters.
