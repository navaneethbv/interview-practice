# Supersequence

A supersequence of a string contains all its letters in the same relative order.
Given lowercase strings, return whether some string with no repeated letter is a supersequence of all of them.

## Examples

### Example 1

```text
Input: arr = ["abc", "bde", "df", "cfe"]
Output: true
Explanation: "abcdfe" works.
```

### Example 2

```text
Input: arr = ["ab", "ba"]
Output: false
```

## Constraints

- `1 <= arr.length` and each string has at most 100 lowercase letters.
