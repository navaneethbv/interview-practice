# Search in Rotated Sorted Array II

The nondecreasing array nums may have been rotated at one pivot.
It can contain duplicates.
Return whether target occurs.

## Constraints

- `1 <= nums.length <= 5000`.
- Values and target range from -10000 to 10000.

## Examples

### Example 1

```text
Input: nums = [2, 2, 3, 0, 1, 2], target = 0
Output: true
Explanation: Zero appears after the rotation pivot.
```

### Example 2

```text
Input: nums = [1, 1, 1], target = 2
Output: false
Explanation: Every element is 1.
```
