# First Unique Character in a String

Return the index of the first character occurring exactly once in `s`, or -1 if no such character exists.

## Examples

### Example 1

```text
Input: s = "swiss"
Output: 1
Explanation: The w at index 1 is the earliest unique character.
```

### Example 2

```text
Input: s = "aabb"
Output: -1
Explanation: Every character repeats.
```

## Constraints

- 1 <= s.length <= 100,000
- s contains lowercase English letters.
