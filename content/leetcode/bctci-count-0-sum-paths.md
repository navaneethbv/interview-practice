# Count 0-Sum Paths

In a binary grid, count the paths from the top-left cell to the bottom-right cell whose cells sum to 0, moving right, down, or diagonally down-right.
Return the count modulo `1,000,000,007`.

## Examples

### Example 1

```text
Input: grid = [[0, 1, 1], [0, 0, 0], [1, 0, 0]]
Output: 7
```

### Example 2

```text
Input: grid = [[0, 0], [0, 0]]
Output: 3
```

## Constraints

- `1 <= rows, columns <= 1,000`
