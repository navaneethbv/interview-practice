# Reconstruct Longest Common Subsequence

Return a longest string that is a subsequence of both `s1` and `s2`.
Any longest common subsequence is accepted.

## Examples

### Example 1

```text
Input: s1 = "HAHAH", s2 = "AAAAHH"
Output: "AAH"
```

### Example 2

```text
Input: s1 = "ABCD", s2 = "ACBAD"
Output: "ACD"
```

## Constraints

- `0 <= s1.length, s2.length <= 1,000`
- Strings contain uppercase English letters.
