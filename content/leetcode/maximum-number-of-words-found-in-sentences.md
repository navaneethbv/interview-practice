# Maximum Number of Words Found in Sentences

Return the largest number of words in any input sentence.
A sentence contains words separated by one space, with no leading or trailing spaces.

## Examples

### Example 1

```text
Input: sentences = ["one two", "three four five", "six"]
Output: 3
Explanation: The second sentence contains three words.
```

### Example 2

```text
Input: sentences = ["hello"]
Output: 1
Explanation: The only sentence is one word.
```

## Constraints

- 1 <= sentences.length <= 100.
- 1 <= sentences[i].length <= 100.
- Sentences contain lowercase English letters and spaces.
