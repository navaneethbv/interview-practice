# Count Primes

Return the number of prime integers strictly smaller than `n`.
A prime is an integer greater than 1 with exactly two positive divisors.

## Examples

### Example 1

```text
Input: n = 10
Output: 4
Explanation: The primes below 10 are 2, 3, 5, and 7.
```

### Example 2

```text
Input: n = 2
Output: 0
Explanation: The bound itself is excluded.
```

## Constraints

- 0 <= n <= 5,000,000
