# Maximum Absolute Sum of Any Subarray

Return the largest absolute value of the sum of a contiguous subarray of nums.
The empty subarray is allowed and has sum zero.

## Constraints

- nums has 1 to 100000 integers from -10000 to 10000.

## Examples

### Example 1

```text
Input: nums = [2, -5, 1]
Output: 5
Explanation: The single -5 has absolute sum 5.
```

### Example 2

```text
Input: nums = [1, 2, 3]
Output: 6
Explanation: The full array has sum 6.
```
