# Longest Balanced Substring I

A substring is balanced when every distinct character appearing in it occurs equally often.
Return the length of the longest balanced substring.

## Examples

### Example 1

```text
Input: s = "aabbc"
Output: 4
Explanation: The prefix aabb contains two of each character.
```

### Example 2

```text
Input: s = "aaaa"
Output: 4
Explanation: A substring with only one distinct character is balanced.
```

## Constraints

- 1 <= s.length <= 1000
- s contains lowercase English letters.
