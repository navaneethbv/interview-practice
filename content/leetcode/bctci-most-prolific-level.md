# Most Prolific Level

The prolificness of a tree level is the average number of children of the nodes on that level.
Return the index of the most prolific level, choosing the smallest index on a tie, or `-1` for an empty tree.

## Examples

### Example 1

```text
Input: root = [1, 2, null, 3, 4, 5, 6, null, 7]
Output: 1
```

### Example 2

```text
Input: root = []
Output: -1
```

## Constraints

- `0 <= number of nodes <= 10^5`
