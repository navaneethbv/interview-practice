# Max Consecutive Ones

Return the length of the longest contiguous run of 1 values in a binary array.

## Examples

### Example 1

```text
Input: nums = [1, 1, 0, 1, 1, 1]
Output: 3
Explanation: The final three values form the longest run.
```

### Example 2

```text
Input: nums = [0, 0]
Output: 0
Explanation: There are no ones.
```

## Constraints

- 1 <= nums.length <= 100000.
- Each value is 0 or 1.
