# Integer to English Words

Convert the nonnegative integer `num` to English words using title case and a single space between words.
Do not use hyphens or the word And.
Use Thousand, Million, and Billion to separate groups.

## Constraints

- `0 <= num <= 2147483647`.

## Examples

### Example 1

```text
Input: num = 42
Output: "Forty Two"
Explanation: The tens and units use separate words.
```

### Example 2

```text
Input: num = 1005
Output: "One Thousand Five"
Explanation: Zero-valued groups and digits add no words.
```
