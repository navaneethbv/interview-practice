# Number of Good Pairs

Count index pairs i < j with equal array values.

## Examples

### Example 1

```text
Input: nums = [1, 2, 3, 1, 1, 3]
Output: 4
Explanation: The three 1 entries make three pairs, and the two 3 entries make one.
```

### Example 2

```text
Input: nums = [1, 2, 3]
Output: 0
Explanation: All entries are distinct.
```

## Constraints

- 1 <= nums.length <= 100
- 1 <= nums[i] <= 100
