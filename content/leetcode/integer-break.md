# Integer Break

Split n into the sum of at least two positive integers and maximize their product.
Return that largest product.
The number of terms is your choice.

## Examples

```text
Input: n = 2
Output: 1
Explanation: Only 1+1 is allowed.
```

```text
Input: n = 10
Output: 36
Explanation: The split 3+3+4 produces 36.
```

## Constraints

- 2 <= n <= 58
- The answer fits a signed 32-bit integer.
