# Longest Repeated Substring

Return the longest substring that occurs at least twice in `s`; occurrences may overlap.
If several have the maximum length, return the one whose first occurrence starts earliest.
Return `""` if no substring repeats.

## Examples

### Example 1

```text
Input: s = "murmur"
Output: "mur"
```

### Example 2

```text
Input: s = "aaaa"
Output: "aaa"
```

## Constraints

- `0 <= s.length <= 10^5`
- `s` contains lowercase English letters.
