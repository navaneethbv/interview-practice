# Maximum Number of Vowels in a Substring of Given Length

Return the largest number of vowels in any contiguous substring of length k.
The vowels are a, e, i, o, and u.

## Examples

### Example 1

```text
Input: s = "abciiidef", k = 3
Output: 3
Explanation: The substring iii contains three vowels.
```

### Example 2

```text
Input: s = "rhythm", k = 2
Output: 0
Explanation: No vowel occurs.
```

## Constraints

- 1 <= k <= s.length <= 100000.
- s contains lowercase English letters.
