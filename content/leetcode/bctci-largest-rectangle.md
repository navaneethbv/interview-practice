# Largest Rectangle

An n by n grid has `tiles[i]` blue cells stacked from the bottom of column i.
All other cells are red.
Return the maximum area of an axis-aligned rectangle containing only whole blue cells.
Return a 64-bit integer in Java.

## Constraints

- 1 <= n = tiles.length <= 1,000,000.
- 0 <= tiles[i] <= n.


## Examples

### Example 1

```text
Input: [[2, 2, 0]]
Output: 4
```

### Example 2

```text
Input: [[1, 3, 2]]
Output: 4
```
