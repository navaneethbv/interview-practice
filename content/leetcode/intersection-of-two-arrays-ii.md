# Intersection of Two Arrays II

Return values present in both arrays, repeating each value the smaller of its two occurrence counts.
The output may be in any order.

## Examples

### Example 1

```text
Input: nums1 = [1, 2, 2, 1], nums2 = [2, 2]
Output: [2, 2]
Explanation: Both arrays contain at least two copies of 2.
```

### Example 2

```text
Input: nums1 = [4, 9, 5], nums2 = [9, 4, 9, 8, 4]
Output: [4, 9]
Explanation: Only one copy of each shared value is available in the first array.
```

## Constraints

- 1 <= nums1.length, nums2.length <= 1,000
- 0 <= nums1[i], nums2[i] <= 1,000
