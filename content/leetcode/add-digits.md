# Add Digits

Repeatedly replace `num` with the sum of its decimal digits until one digit remains.
Return that final digit.

## Examples

### Example 1

```text
Input: num = 38
Output: 2
Explanation: 38 becomes 11, then 2.
```

### Example 2

```text
Input: num = 0
Output: 0
Explanation: Zero already has one digit.
```

## Constraints

- 0 <= num <= 2^31 - 1
