# Max Points on a Line

Return the greatest number of distinct input points lying on one straight line.

## Examples

### Example 1

```text
Input: points = [[1, 1], [2, 2], [3, 3]]
Output: 3
Explanation: All points lie on y = x.
```

### Example 2

```text
Input: points = [[0, 0], [1, 1], [1, 0], [2, 0]]
Output: 3
Explanation: Three points lie on the horizontal axis.
```

## Constraints

- 1 <= points.length <= 300
- Each point contains x and y coordinates from -10,000 through 10,000.
- All points are distinct.
