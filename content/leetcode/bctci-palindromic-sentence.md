# Palindromic Sentence

Return whether the letters of `s` form a palindrome when case, spaces, punctuation, and digits are ignored.
Only the letters `a` to `z` and `A` to `Z` are considered.

## Examples

### Example 1

```text
Input: s = "Bob wondered, 'Now, Bob?'"
Output: true
```

### Example 2

```text
Input: s = "race a car"
Output: false
```

## Constraints

- `0 <= s.length <= 10^6`
- `s` consists of printable ASCII characters.
