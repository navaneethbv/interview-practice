# Sort Array By Parity

Rearrange nums so every even number comes before every odd number.
Preserve all occurrences, but order within either parity group is unrestricted.

## Constraints

- nums contains 1 to 5000 integers from 0 to 5000.

## Examples

### Example 1

```text
Input: nums = [3, 2, 1, 4]
Output: [2, 4, 3, 1]
Explanation: Even values 2 and 4 precede both odd values.
```

### Example 2

```text
Input: nums = [0]
Output: [0]
Explanation: Zero is even.
```
