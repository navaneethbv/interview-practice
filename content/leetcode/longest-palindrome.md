# Longest Palindrome

Return the largest length of a palindrome that can be built by rearranging some or all characters of `s`.
Uppercase and lowercase versions of a letter are different characters.

## Examples

### Example 1

```text
Input: s = "abccccdd"
Output: 7
Explanation: Use all paired characters and one extra character as the center.
```

### Example 2

```text
Input: s = "Aa"
Output: 1
Explanation: The two differently cased letters cannot pair.
```

## Constraints

- 1 <= s.length <= 2,000
- s contains uppercase and lowercase English letters.
