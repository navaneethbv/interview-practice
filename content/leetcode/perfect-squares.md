# Perfect Squares

Return the fewest perfect-square positive integers whose sum is `n`.
A square may be used repeatedly.

## Examples

### Example 1

```text
Input: n = 12
Output: 3
Explanation: Use 4 + 4 + 4.
```

### Example 2

```text
Input: n = 13
Output: 2
Explanation: Use 9 + 4.
```

## Constraints

- 1 <= n <= 10,000
