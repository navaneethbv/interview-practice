# Longest Common Prefix

Return the longest starting sequence of characters shared by every string in `strs`.
Return the empty string if there is no shared prefix.

## Examples

### Example 1

```text
Input: strs = ["flower", "flow", "flight"]
Output: "fl"
Explanation: All three words begin with fl.
```

### Example 2

```text
Input: strs = ["dog", "racecar", "car"]
Output: ""
Explanation: No first character is common.
```

## Constraints

- 1 <= strs.length <= 200
- 0 <= strs[i].length <= 200
- Strings contain lowercase English letters.
