# Most Sales in k Days

Return the first day of the `k`-day period with the most sales.
If several periods tie, return the earliest start.

## Examples

### Example 1

```text
Input: sales = [8, 1, 3, 7], k = 2
Output: 2
```

### Example 2

```text
Input: sales = [5, 10, 15, 5], k = 1
Output: 2
```

## Constraints

- `1 <= k <= sales.length <= 10^6`
- `0 <= sales[i] < 10^3`
