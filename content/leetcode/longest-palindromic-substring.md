# Longest Palindromic Substring

Return a longest contiguous substring of `s` that reads the same forwards and backwards.
If several substrings have the maximum length, any one is accepted.

## Constraints

- `1 <= s.length <= 1000`.
- `s` contains English letters and digits.
- Comparison is case sensitive.

## Examples

### Example 1

```text
Input: s = "cabbad"
Output: "abba"
Explanation: The middle four characters form the longest palindrome.
```

### Example 2

```text
Input: s = "xyz"
Output: "x"
Explanation: Every one-character substring is a maximum-length answer.
```
