# Longest Balanced Substring II

The string uses only a, b, and c.
Return the greatest length of a substring in which every character that appears has the same frequency.
Characters absent from the substring impose no requirement.

## Examples

### Example 1

```text
Input: s = "aabbc"
Output: 4
Explanation: The prefix aabb has equal counts of a and b.
```

### Example 2

```text
Input: s = "cccc"
Output: 4
Explanation: The entire string contains just one character.
```

## Constraints

- 1 <= s.length <= 100000
- Every character is a, b, or c.
