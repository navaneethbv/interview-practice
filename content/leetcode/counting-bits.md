# Counting Bits

Return an array of length `n + 1` where entry `i` counts the 1 bits in the binary representation of `i`.
Aim for O(n) total time.

## Examples

### Example 1

```text
Input: n = 3
Output: [0, 1, 1, 2]
Explanation: The representations 0, 1, 10, and 11 have these counts.
```

### Example 2

```text
Input: n = 6
Output: [0, 1, 1, 2, 1, 2, 2]
Explanation: The result includes every integer through 6.
```

## Constraints

- 0 <= n <= 100,000
