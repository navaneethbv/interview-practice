# Kth Missing Positive Number

Given a strictly increasing array of positive integers, return the kth positive integer absent from it.

## Examples

### Example 1

```text
Input: arr = [2, 3, 4, 7, 11], k = 5
Output: 9
Explanation: The first missing numbers are 1, 5, 6, 8, 9.
```

### Example 2

```text
Input: arr = [1, 2, 3, 4], k = 2
Output: 6
Explanation: The missing numbers start at 5.
```

## Constraints

- 1 <= arr.length <= 1,000
- 1 <= arr[i], k <= 1,000
- arr is strictly increasing.
