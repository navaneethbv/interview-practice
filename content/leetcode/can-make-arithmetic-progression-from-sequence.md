# Can Make Arithmetic Progression From Sequence

Return whether rearranging arr can produce a sequence with one constant difference between every adjacent pair.
A difference of zero is allowed.

## Constraints

- arr has 2 to 1000 integers from -1000000 to 1000000.

## Examples

### Example 1

```text
Input: arr = [5, 1, 3]
Output: true
Explanation: Sorted order 1,3,5 has difference 2.
```

### Example 2

```text
Input: arr = [1, 2, 4]
Output: false
Explanation: No arrangement has one common difference.
```
