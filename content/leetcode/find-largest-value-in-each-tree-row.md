# Find Largest Value in Each Tree Row

Return the maximum node value at each tree depth, ordered from root to deepest level.
An empty tree gives an empty list.

## Constraints

- The tree contains 0 to 10000 nodes.
- Values fit in signed 32-bit integers.

## Examples

### Example 1

```text
Input: root = [2, 5, 1, 3, 4]
Output: [2, 5, 4]
Explanation: The level maxima are 2, 5, and 4.
```

### Example 2

```text
Input: root = []
Output: []
Explanation: There are no levels.
```
