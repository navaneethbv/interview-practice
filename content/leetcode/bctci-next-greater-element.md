# Next Greater Element

For each position in `arr`, return the index of the first strictly larger value to its right.
Use -1 when no such position exists.
Equal values do not qualify.

## Constraints

- 1 <= arr.length <= 100,000.
- -1,000,000,000 <= arr[i] <= 1,000,000,000.


## Examples

### Example 1

```text
Input: [[2, 2, 4, 3]]
Output: [2, 2, -1, -1]
```

### Example 2

```text
Input: [[5, 1, 2]]
Output: [-1, 2, -1]
```
