# Unique Paths

A robot starts in the top-left cell of an `m` by `n` grid and must reach the bottom-right cell.
Each move goes exactly one cell right or one cell down.
Return the number of distinct routes.

## Examples

### Example 1

```text
Input: m = 3, n = 4
Output: 10
Explanation: Each route contains two down moves and three right moves, in any order.
```

### Example 2

```text
Input: m = 1, n = 5
Output: 1
Explanation: There is only a straight route to the right.
```

## Constraints

- 1 <= m, n <= 100
- The answer is at most 2,000,000,000.
