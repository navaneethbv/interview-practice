# Unrooted Tree Diameter

The undirected edges connect all n vertices, numbered 0 through n - 1, into a tree.
Return the largest number of edges on a path between any two vertices.

## Constraints

- 1 <= n <= 10,000.
- edges.length = n - 1; endpoints are valid and there are no cycles.


## Examples

### Example 1

```text
Input: [4, [[0, 1], [1, 2], [1, 3]]]
Output: 2
```

### Example 2

```text
Input: [1, []]
Output: 0
```
