# Binary Tree Inorder Traversal

Return tree values in inorder: visit the left subtree, then the current node, then the right subtree.

## Examples

### Example 1

```text
Input: root = [1, null, 2, 3]
Output: [1, 3, 2]
Explanation: Visit node 1, the left child of 2, and then node 2.
```

### Example 2

```text
Input: root = []
Output: []
Explanation: An empty tree contributes no values.
```

## Constraints

- The tree contains 0 through 100 nodes.
- -100 <= Node.val <= 100
