# Pascal's Triangle

Return the first numRows rows of Pascal's triangle.
Each row begins and ends with 1, and each interior value is the sum of the two values above it.

## Examples

### Example 1

```text
Input: numRows = 3
Output: [[1], [1, 1], [1, 2, 1]]
Explanation: The third row has the interior sum 1 + 1.
```

### Example 2

```text
Input: numRows = 1
Output: [[1]]
Explanation: Only the initial row is needed.
```

## Constraints

- 1 <= numRows <= 30.
