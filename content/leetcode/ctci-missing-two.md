# Missing Two

An array contains every integer from 1 to `n` exactly once, except that two of them are missing, so its length is `n - 2`.
Return the two missing numbers in increasing order.
Aim for O(n) time and O(1) extra space.

## Examples

### Example 1

```text
Input: nums = [1, 3, 5]
Output: [2, 4]
```

### Example 2

```text
Input: nums = []
Output: [1, 2]
```

## Constraints

- `0 <= nums.length <= 100,000`
