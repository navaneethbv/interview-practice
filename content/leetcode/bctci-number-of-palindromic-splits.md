# Number of Palindromic Splits

A palindromic split divides `s` into consecutive pieces that are all palindromes.
Return the number of palindromic splits of `s` modulo `1,000,000,007`; an empty string has 0.

## Examples

### Example 1

```text
Input: s = "abbaab"
Output: 6
```

### Example 2

```text
Input: s = "aaaaa"
Output: 16
```

## Constraints

- `0 <= s.length <= 2,000`
- `s` contains lowercase English letters.
