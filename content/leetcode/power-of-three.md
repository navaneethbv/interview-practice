# Power of Three

Return whether n equals 3 raised to a nonnegative integer power.
The value 1 qualifies.

## Examples

### Example 1

```text
Input: n = 81
Output: true
Explanation: 81 equals 3 to the power 4.
```

### Example 2

```text
Input: n = 45
Output: false
Explanation: 45 is not an exact power of 3.
```

## Constraints

- n is a signed 32-bit integer.
