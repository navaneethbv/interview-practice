# Spiral Matrix II

Construct an n by n matrix containing the integers 1 through n squared in clockwise spiral order.
Start at the top-left corner and initially move right.

## Examples

### Example 1

```text
Input: n = 2
Output: [[1, 2], [4, 3]]
Explanation: The numbers follow the boundary clockwise.
```

### Example 2

```text
Input: n = 3
Output: [[1, 2, 3], [8, 9, 4], [7, 6, 5]]
Explanation: After filling the boundary, place 9 at the center.
```

## Constraints

- 1 <= n <= 20.
