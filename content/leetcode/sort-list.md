# Sort List

Return the linked list sorted by node value in ascending order.
Aim for O(n log n) time and constant auxiliary space.

## Examples

### Example 1

```text
Input: head = [4, 2, 1, 3]
Output: [1, 2, 3, 4]
Explanation: Arrange all values in ascending order.
```

### Example 2

```text
Input: head = []
Output: null
Explanation: An empty list is returned as a null head.
```

## Constraints

- The list contains 0 through 50,000 nodes.
- -100,000 <= Node.val <= 100,000
