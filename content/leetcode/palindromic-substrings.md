# Palindromic Substrings

Count the contiguous substrings of `s` that are palindromes.
Substrings with different start or end positions count separately even if their text is identical.

## Constraints

- `1 <= s.length <= 1000`.
- `s` contains lowercase English letters.

## Examples

### Example 1

```text
Input: s = "abba"
Output: 6
Explanation: There are four single characters, bb, and abba.
```

### Example 2

```text
Input: s = "aaaa"
Output: 10
Explanation: All 4 + 3 + 2 + 1 substrings are palindromes.
```
