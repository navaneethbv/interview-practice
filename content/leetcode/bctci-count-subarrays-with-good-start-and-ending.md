# Count Subarrays With Good Start and Ending

A bad day has fewer than 10 sales and a good day has at least 10.
Return how many subarrays both start and end on a good day.

## Examples

### Example 1

```text
Input: sales = [0, 20, 5, 15, 10]
Output: 6
```

### Example 2

```text
Input: sales = [0, 5, 8]
Output: 0
```

## Constraints

- `0 <= sales.length <= 10^5`
- `0 <= sales[i] < 10^3`
