# Remove Duplicates from Sorted List

Remove repeated values from a sorted linked list so each value appears once.
Return the updated list head.

## Examples

### Example 1

```text
Input: head = [1, 1, 2]
Output: [1, 2]
Explanation: Remove the repeated node containing 1.
```

### Example 2

```text
Input: head = [1, 1, 2, 3, 3]
Output: [1, 2, 3]
Explanation: Retain one occurrence of each distinct value.
```

## Constraints

- The list contains 0 through 300 nodes.
- -100 <= Node.val <= 100
- Node values are sorted in nondecreasing order.
