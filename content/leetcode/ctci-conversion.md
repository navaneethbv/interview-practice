# Conversion

Return how many bits must be flipped to turn integer `a` into integer `b`.
Both are 32-bit two's complement integers.

## Examples

### Example 1

```text
Input: a = 29, b = 15
Output: 2
Explanation: 11101 and 01111 differ in two positions.
```

### Example 2

```text
Input: a = -1, b = 0
Output: 32
```

## Constraints

- `-2^31 <= a, b <= 2^31 - 1`
