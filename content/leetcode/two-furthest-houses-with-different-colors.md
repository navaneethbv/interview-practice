# Two Furthest Houses With Different Colors

Houses are arranged in array order.
Return the largest index distance between two houses of different colors.

## Examples

### Example 1

```text
Input: colors = [1, 1, 1, 6, 1, 1, 1]
Output: 3
Explanation: The uniquely colored middle house is three positions from either end.
```

### Example 2

```text
Input: colors = [1, 8, 3, 8, 3]
Output: 4
Explanation: The two endpoint colors differ.
```

## Constraints

- 2 <= colors.length <= 100
- 0 <= colors[i] <= 100
- At least two different colors occur.
