# Fibonacci Number

Return F(n), where F(0)=0, F(1)=1, and each later value is the sum of the previous two.

## Examples

### Example 1

```text
Input: n = 4
Output: 3
Explanation: The sequence begins 0, 1, 1, 2, 3.
```

### Example 2

```text
Input: n = 6
Output: 8
Explanation: F(6) equals 5 + 3.
```

## Constraints

- 0 <= n <= 30
