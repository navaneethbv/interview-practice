# Maximum Subarray

Find the largest sum of a nonempty contiguous segment of `nums`.

## Examples

### Example 1

```text
Input: nums = [-3, 4, -1, 2, -6]
Output: 5
Explanation: The segment [4, -1, 2] sums to 5.
```

### Example 2

```text
Input: nums = [-5, -2, -8]
Output: -2
Explanation: A segment must contain an entry, so choose -2.
```

## Constraints

- 1 <= nums.length <= 100,000
- -10,000 <= nums[i] <= 10,000
