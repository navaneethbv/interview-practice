# Parity Sorting

Rearrange `arr` in place so that every even number comes before every odd number.
The order within the evens and within the odds does not matter; any valid arrangement is accepted.

## Examples

### Example 1

```text
Input: arr = [1, 2, 3, 4, 5]
Output: [4, 2, 3, 1, 5]
```

### Example 2

```text
Input: arr = [5, 1, 3, 1, 5]
Output: [5, 1, 3, 1, 5]
```

## Constraints

- `0 <= arr.length <= 10^6`
- `-10^9 <= arr[i] <= 10^9`
