# Kth Multiple

Consider the increasing sequence of positive integers whose only prime factors are 3, 5, and 7: 1, 3, 5, 7, 9, 15, 21, and so on.
The number 1 counts as the first element.
Return the `k`th element.

## Examples

### Example 1

```text
Input: k = 6
Output: 15
```

### Example 2

```text
Input: k = 1
Output: 1
```

## Constraints

- `1 <= k <= 2,000`
- The answer fits in a signed 64-bit integer.
