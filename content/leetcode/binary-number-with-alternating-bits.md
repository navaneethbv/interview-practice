# Binary Number with Alternating Bits

Return whether adjacent digits in the binary representation of positive n always differ.
Ignore leading zeros.

## Examples

### Example 1

```text
Input: n = 5
Output: true
Explanation: The binary representation 101 alternates.
```

### Example 2

```text
Input: n = 7
Output: false
Explanation: Binary 111 repeats neighboring bits.
```

## Constraints

- 1 <= n <= 2^31 - 1
