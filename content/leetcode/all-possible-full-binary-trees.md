# All Possible Full Binary Trees

A full binary tree is one in which every node has either zero or two children.
Return every full binary tree with exactly `n` nodes, where every node has value 0.
Each tree is shown in level order; the trees may be returned in any order.

Any order of the result is accepted.

## Constraints

- 1 <= n <= 20

## Examples

### Example 1

```text
Input: n = 3
Output: [[0, 0, 0]]
Explanation: Only one tree has three nodes: a root with two leaves.
```

### Example 2

```text
Input: n = 2
Output: []
Explanation: Full trees always have an odd number of nodes.
```
