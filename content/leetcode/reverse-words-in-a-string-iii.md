# Reverse Words in a String III

Reverse the characters inside each word while leaving the words in their original order.
Preserve the single spaces separating the words.

## Examples

### Example 1

```text
Input: s = "code every day"
Output: "edoc yreve yad"
Explanation: Reverse each of the three words separately.
```

### Example 2

```text
Input: s = "ab cd"
Output: "ba dc"
Explanation: The space remains between the same words.
```

## Constraints

- 1 <= s.length <= 50000.
- s contains printable ASCII characters.
- There are no leading or trailing spaces, and words are separated by one space.
