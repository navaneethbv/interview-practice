# Maximum Swap

You may swap at most one pair of decimal digits of `num`.
Return the largest integer obtainable, including the choice to make no swap.

## Examples

### Example 1

```text
Input: num = 2736
Output: 7236
Explanation: Swap the first two digits.
```

### Example 2

```text
Input: num = 9973
Output: 9973
Explanation: No swap improves the number.
```

## Constraints

- 0 <= num <= 10^8
