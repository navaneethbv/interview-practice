# Recursive Multiply

Multiply two positive integers recursively without using the `*` or `/` operators.
Addition, subtraction, and bit shifts are allowed; aim for as few of them as possible.

## Examples

### Example 1

```text
Input: a = 7, b = 8
Output: 56
```

### Example 2

```text
Input: a = 1, b = 99
Output: 99
```

## Constraints

- `1 <= a, b`
- `a * b <= 2^31 - 1`
