# Find Numbers with Even Number of Digits

Count the array entries whose decimal representation has an even number of digits.

## Examples

### Example 1

```text
Input: nums = [12, 345, 2, 6, 7896]
Output: 2
Explanation: 12 and 7896 have even digit counts.
```

### Example 2

```text
Input: nums = [1, 10, 100, 1000]
Output: 2
Explanation: 10 and 1000 qualify.
```

## Constraints

- 1 <= nums.length <= 500
- 1 <= nums[i] <= 100000
