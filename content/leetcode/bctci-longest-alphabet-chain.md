# Longest Alphabet Chain

Reorder any subset of the characters in `arr` into the longest possible chain where each letter is followed by the next alphabet letter.
After z, the next letter is a.
Each occurrence may be used at most once.
Return the maximum chain length, or 0 for empty input.

## Constraints

- 0 <= arr.length <= 100,000.
- arr contains lowercase English letters.


## Examples

### Example 1

```text
Input: ["azbc"]
Output: 4
```

### Example 2

```text
Input: ["aaccee"]
Output: 1
```
