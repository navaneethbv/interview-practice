# Permutations

Return every possible ordering of the distinct entries in `nums`.
Each ordering must use every entry exactly once; the list of orderings may appear in any order.

## Examples

### Example 1

```text
Input: nums = [1, 2]
Output: [[1, 2], [2, 1]]
Explanation: Either value can appear first.
```

### Example 2

```text
Input: nums = [0]
Output: [[0]]
Explanation: There is just one ordering of a single value.
```

## Constraints

- 1 <= nums.length <= 6
- -10 <= nums[i] <= 10
- All entries are distinct.
