# Smallest K

Return the `k` smallest numbers in `arr`, in any order.
Values may repeat, and each occurrence counts separately.

## Examples

### Example 1

```text
Input: arr = [1, 3, 5, 7, 2, 4, 6, 8], k = 4
Output: [1, 2, 3, 4]
```

### Example 2

```text
Input: arr = [5, 5, 5], k = 2
Output: [5, 5]
```

## Constraints

- `0 <= k <= arr.length <= 100,000`
- `-10^9 <= arr[i] <= 10^9`
