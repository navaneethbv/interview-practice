# Contains Duplicate

Return whether any value occurs at least twice in `nums`.

## Examples

### Example 1

```text
Input: nums = [6, 2, 8, 6]
Output: true
Explanation: The value 6 appears twice.
```

### Example 2

```text
Input: nums = [0, -1, 2]
Output: false
Explanation: All entries are different.
```

## Constraints

- 1 <= nums.length <= 100,000
- -10^9 <= nums[i] <= 10^9
