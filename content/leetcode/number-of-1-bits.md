# Number of 1 Bits

Return how many bits are set to 1 in the binary representation of the positive integer `n`.

## Examples

### Example 1

```text
Input: n = 13
Output: 3
Explanation: 13 is binary 1101, which contains three set bits.
```

### Example 2

```text
Input: n = 16
Output: 1
Explanation: A power of two has one set bit.
```

## Constraints

- 1 <= n <= 2^31 - 1
