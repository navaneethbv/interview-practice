# Sqrt(x)

Return the greatest integer whose square is no larger than x.
Do not use a built-in square-root function or exponentiation to a fractional power.

## Examples

### Example 1

```text
Input: x = 20
Output: 4
Explanation: 4 squared is 16, while 5 squared is 25.
```

### Example 2

```text
Input: x = 25
Output: 5
Explanation: 25 is an exact square.
```

## Constraints

- 0 <= x <= 2147483647.
