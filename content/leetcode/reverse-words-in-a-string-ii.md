# Reverse Words in a String II

Reverse the order of words in the character array s in place.
Keep the characters within each word in their original order and use O(1) extra storage.
The judge reads the modified array after the method returns.

## Constraints

- s has 1 to 100000 ASCII letters, digits, and spaces.
- Words are separated by exactly one space, with no leading or trailing space.

## Examples

### Example 1

```text
Input: s = ["o", "n", "e", " ", "t", "w", "o"]
Output: ["t", "w", "o", " ", "o", "n", "e"]
Explanation: The word order reverses while spelling is retained.
```

### Example 2

```text
Input: s = ["s", "o", "l", "o"]
Output: ["s", "o", "l", "o"]
Explanation: One word stays unchanged.
```
