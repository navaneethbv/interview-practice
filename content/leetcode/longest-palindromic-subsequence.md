# Longest Palindromic Subsequence

Return the maximum length of a palindrome obtainable by deleting zero or more characters from `s` without changing the order of those retained.
The retained characters need not be contiguous.

## Constraints

- `1 <= s.length <= 1000`.
- `s` contains lowercase English letters.

## Examples

### Example 1

```text
Input: s = "agbdba"
Output: 5
Explanation: Deleting g leaves the palindrome abdba.
```

### Example 2

```text
Input: s = "abc"
Output: 1
Explanation: Only one-character palindromes are possible.
```
