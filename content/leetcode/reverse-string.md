# Reverse String

Reverse the characters of s in place using constant additional space.
Return nothing; the judge displays the changed character array.

## Examples

### Example 1

```text
Input: s = ["h", "e", "l", "l", "o"]
Output: ["o", "l", "l", "e", "h"]
Explanation: The first and last characters trade places, then the inner pair.
```

### Example 2

```text
Input: s = ["a"]
Output: ["a"]
Explanation: One character remains unchanged.
```

## Constraints

- 1 <= s.length <= 100000.
- Characters are printable ASCII.
