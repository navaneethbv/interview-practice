# Power of Two

Return whether n equals 2 raised to a nonnegative integer power.
The value 1 qualifies because it is 2 to the power 0.

## Examples

### Example 1

```text
Input: n = 32
Output: true
Explanation: 32 is 2 to the power 5.
```

### Example 2

```text
Input: n = 12
Output: false
Explanation: 12 lies between consecutive powers 8 and 16.
```

## Constraints

- n is a signed 32-bit integer.
