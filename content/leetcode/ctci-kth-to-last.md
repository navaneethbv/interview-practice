# Return Kth to Last

Given the head of a singly linked list and an integer `k`, return the value of the `k`th node from the end.
`k = 1` refers to the last node.
`k` is always between 1 and the length of the list.

## Examples

### Example 1

```text
Input: head = [1, 2, 3, 4, 5], k = 2
Output: 4
```

### Example 2

```text
Input: head = [8], k = 1
Output: 8
```

## Constraints

- `1 <= number of nodes <= 100,000`
- `1 <= k <= number of nodes`
