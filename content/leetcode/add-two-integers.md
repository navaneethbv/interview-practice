# Add Two Integers

Return the sum of the two signed integers.

## Examples

### Example 1

```text
Input: num1 = 12, num2 = 5
Output: 17
Explanation: Add the two positive values.
```

### Example 2

```text
Input: num1 = -10, num2 = 4
Output: -6
Explanation: Adding 4 moves -10 toward zero.
```

## Constraints

- -100 <= num1, num2 <= 100
