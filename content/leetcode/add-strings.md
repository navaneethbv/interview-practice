# Add Strings

Add the two nonnegative decimal integers represented by num1 and num2.
Return their sum as a decimal string.
Process the digits directly without converting either whole input to an integer or using a big-integer library.

## Examples

### Example 1

```text
Input: num1 = "95", num2 = "17"
Output: "112"
Explanation: Adding the units produces a carry.
```

### Example 2

```text
Input: num1 = "0", num2 = "0"
Output: "0"
Explanation: The sum is zero.
```

## Constraints

- 1 <= num1.length, num2.length <= 10000.
- Inputs contain digits and have no leading zero unless equal to 0.
