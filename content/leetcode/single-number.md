# Single Number

Exactly one value in `nums` appears once; every other value appears twice.
Return the value that appears once using linear time and constant extra space.

## Examples

### Example 1

```text
Input: nums = [4, 1, 4]
Output: 1
Explanation: Only 1 has no matching duplicate.
```

### Example 2

```text
Input: nums = [-2]
Output: -2
Explanation: The sole entry is the answer.
```

## Constraints

- 1 <= nums.length <= 30,000
- -30,000 <= nums[i] <= 30,000
- Exactly one value occurs once and all others occur twice.
