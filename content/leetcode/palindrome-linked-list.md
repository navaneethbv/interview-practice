# Palindrome Linked List

Return whether the linked-list values read the same from head to tail and from tail to head.
Try to use linear time and constant auxiliary space.

## Examples

### Example 1

```text
Input: head = [1, 2, 2, 1]
Output: true
Explanation: The value sequence is unchanged when reversed.
```

### Example 2

```text
Input: head = [1, 2]
Output: false
Explanation: The first and last values differ.
```

## Constraints

- The list contains 1 through 100,000 nodes.
- 0 <= Node.val <= 9
