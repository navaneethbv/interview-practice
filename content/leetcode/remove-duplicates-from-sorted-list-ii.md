# Remove Duplicates from Sorted List II

Given a sorted linked list, remove every value that occurs more than once.
Return a list containing only the values that appeared exactly once, preserving sorted order.

## Constraints

- The list contains 0 to 300 nodes.
- Values range from -100 to 100 and are sorted ascending.

## Examples

### Example 1

```text
Input: head = [1, 2, 2, 3]
Output: [1, 3]
Explanation: Both nodes with value 2 are removed.
```

### Example 2

```text
Input: head = [1, 1]
Output: null
Explanation: No value appears exactly once.
```
