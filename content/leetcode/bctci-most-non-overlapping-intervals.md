# Most Non-Overlapping Intervals

Each interval `[l, r]` includes both endpoints.
Return the largest number of intervals you can choose so that no two chosen intervals share a point.

## Examples

### Example 1

```text
Input: intervals = [[2, 3], [1, 4], [2, 3], [3, 6], [8, 9]]
Output: 2
```

### Example 2

```text
Input: intervals = [[1, 10], [8, 9], [2, 3]]
Output: 2
```

## Constraints

- `0 <= intervals.length <= 10^5`
- `0 <= l <= r <= 10^9`
