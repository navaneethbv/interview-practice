# Shortest With All Letters

Return the length of the shortest substring of `s1` that contains every letter of `s2` at least as many times as it appears in `s2`, or `-1` if none exists.

## Examples

### Example 1

```text
Input: s1 = "helloworld", s2 = "well"
Output: 5
```

### Example 2

```text
Input: s1 = "helloworld", s2 = "weelll"
Output: -1
```

## Constraints

- `1 <= s2.length < s1.length <= 10^5`
- All characters are lowercase English letters.
