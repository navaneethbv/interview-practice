# Split a String in Balanced Strings

Split s into the largest number of nonempty contiguous pieces, each containing equally many L and R characters.
Use every character.

## Constraints

- s contains 2 to 1000 characters, all L or R.
- The complete string has equal counts of both letters.

## Examples

### Example 1

```text
Input: s = "LRLR"
Output: 2
Explanation: Split into LR and LR.
```

### Example 2

```text
Input: s = "LLRR"
Output: 1
Explanation: The balance first returns to zero at the end.
```
