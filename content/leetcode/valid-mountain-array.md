# Valid Mountain Array

Return whether arr strictly increases to a single interior peak and then strictly decreases.
Both the increasing and decreasing parts must contain at least one step; equal neighbors are forbidden.

## Constraints

- arr contains 1 to 10000 integers from 0 to 10000.

## Examples

### Example 1

```text
Input: arr = [1, 4, 2]
Output: true
Explanation: The interior value 4 is a strict peak.
```

### Example 2

```text
Input: arr = [1, 2, 3]
Output: false
Explanation: There is no decreasing part.
```
