# Palindrome Number

Return whether the decimal representation of `x` reads identically forward and backward.
A negative sign makes every negative value non-palindromic.

## Examples

### Example 1

```text
Input: x = 121
Output: true
Explanation: The digits are unchanged when reversed.
```

### Example 2

```text
Input: x = -121
Output: false
Explanation: The minus sign would move to the other end.
```

## Constraints

- -2^31 <= x <= 2^31 - 1
