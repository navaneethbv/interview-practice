# Add Two Numbers

Two nonempty linked lists store nonnegative integers in reverse digit order.
Add the integers and return their sum in the same format.
Each node stores one digit, and only the number zero may have a leading zero in its usual representation.

## Examples

### Example 1

```text
Input: l1 = [2, 4, 3], l2 = [5, 6, 4]
Output: [7, 0, 8]
Explanation: 342 + 465 = 807.
```

### Example 2

```text
Input: l1 = [0], l2 = [0]
Output: [0]
Explanation: Zero plus zero remains zero.
```

## Constraints

- Each list has 1 through 100 nodes.
- 0 <= Node.val <= 9
