# Water Refilling

A container holds `a` gallons and a smaller one holds `b` gallons, with `a > b`.
Return how many times you can pour a full `b`-gallon container into the empty `a`-gallon container without overflowing it.
Do not use division; halving with the right-shift operator is allowed.

## Examples

### Example 1

```text
Input: a = 18, b = 5
Output: 3
```

### Example 2

```text
Input: a = 10, b = 2
Output: 5
```

## Constraints

- `1 <= b < a <= 10^9`
