# Binary Tree Maximum Path Sum

A path is a nonempty sequence of connected nodes that never visits a node twice.
It may start and end anywhere in the tree and need not include the root.
Return the largest possible sum of values on one path.

## Constraints

- The tree contains 1 to 30000 nodes.
- Node values range from -1000 to 1000.

## Examples

### Example 1

```text
Input: root = [2, -1, 4]
Output: 6
Explanation: The path from 2 to 4 sums to 6.
```

### Example 2

```text
Input: root = [-8, -2, -5]
Output: -2
Explanation: A path may consist of the single node -2.
```
