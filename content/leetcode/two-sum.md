# Two Sum

Return the indices of two different entries in `nums` whose sum equals `target`.
Exactly one pair exists, and its indices may be returned in either order.

## Examples

### Example 1

```text
Input: nums = [4, 8, 1, 6], target = 10
Output: [0, 3]
Explanation: The entries at indices 0 and 3 add to 10.
```

### Example 2

```text
Input: nums = [5, 5], target = 10
Output: [0, 1]
Explanation: The two equal entries occupy different indices.
```

## Constraints

- 2 <= nums.length <= 10,000
- -10^9 <= nums[i], target <= 10^9
- Exactly one valid pair exists.
