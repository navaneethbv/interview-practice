# Sort Array by Increasing Frequency

Sort entries by increasing frequency in nums.
Values occurring equally often are ordered by decreasing numeric value.
Return the sorted array.

## Examples

### Example 1

```text
Input: nums = [1, 1, 2, 2, 2, 3]
Output: [3, 1, 1, 2, 2, 2]
Explanation: Three appears once, one twice, and two three times.
```

### Example 2

```text
Input: nums = [2, 3, 1]
Output: [3, 2, 1]
Explanation: Equal frequencies use descending value order.
```

## Constraints

- 1 <= nums.length <= 100
- -100 <= nums[i] <= 100
