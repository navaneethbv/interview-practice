# Remove Linked List Elements

Remove every linked-list node whose value equals `val` and return the new head.
Preserve the order of retained nodes.

## Constraints

- The list contains 0 to 10000 nodes.
- Node values and val range from 1 to 50.

## Examples

### Example 1

```text
Input: head = [2, 1, 2, 3], val = 2
Output: [1, 3]
Explanation: Both nodes containing 2 are removed.
```

### Example 2

```text
Input: head = [4, 4], val = 4
Output: null
Explanation: All nodes are removed.
```
