# Exclusive Product

Return an array whose entry `i` is the product of every element of `arr` except `arr[i]`, modulo `1,000,000,007`.
Do not use division.

## Examples

### Example 1

```text
Input: arr = [1, 3, 2, 1]
Output: [6, 2, 3, 6]
```

### Example 2

```text
Input: arr = [0, 1, 0]
Output: [0, 0, 0]
```

## Constraints

- `2 <= arr.length <= 10^6`
- `0 <= arr[i] <= 10^4`
