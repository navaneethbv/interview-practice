# Spiral Order

Given a positive odd integer `n`, return an `n x n` grid containing the numbers 0 to `n^2 - 1` in spiral order.
Place 0 at the center, move down for the first step, and turn clockwise each time the spiral turns.

## Examples

### Example 1

```text
Input: n = 3
Output: [[4, 5, 6], [3, 0, 7], [2, 1, 8]]
```

### Example 2

```text
Input: n = 1
Output: [[0]]
```

## Constraints

- `1 <= n < 1000` and `n` is odd.
