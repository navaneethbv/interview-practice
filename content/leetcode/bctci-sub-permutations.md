# Sub Permutations

Count distinct strings that both rearrange all letters of `s1` and occur as contiguous substrings of `s2`.
Count a matching string once even if it appears at multiple positions.

## Constraints

- 1 <= s1.length <= 100.
- s1.length <= s2.length <= 100,000.
- Both strings contain lowercase English letters.


## Examples

### Example 1

```text
Input: ["ab", "ababba"]
Output: 2
```

### Example 2

```text
Input: ["a", "aaaa"]
Output: 1
```
