# First Letter to Appear Twice

Scan s from left to right and return the character whose second occurrence is encountered first.

## Constraints

- `2 <= s.length <= 100`.
- Characters are lowercase English letters and at least one repeats.

## Examples

### Example 1

```text
Input: s = "abcbad"
Output: "b"
Explanation: The second b appears before the second a.
```

### Example 2

```text
Input: s = "zz"
Output: "z"
Explanation: The second character repeats z.
```
