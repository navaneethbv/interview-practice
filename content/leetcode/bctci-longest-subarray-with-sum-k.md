# Longest Subarray With Sum K

Return the length of the longest subarray of `arr` whose elements sum to `k`, or `-1` if there is none.

## Examples

### Example 1

```text
Input: arr = [1, 2, 3, 2, 1], k = 3
Output: 2
```

### Example 2

```text
Input: arr = [-1, -2, -3, 2, 1], k = -3
Output: 5
```

## Constraints

- `0 <= arr.length <= 10^5`
- `-10^4 <= arr[i] <= 10^4`
