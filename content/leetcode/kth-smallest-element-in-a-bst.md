# Kth Smallest Element in a BST

Return the `k`th smallest value in a binary search tree, counting from 1.
All tree values are distinct.

## Constraints

- The tree contains 1 to 10000 nodes.
- `1 <= k <= node count`.
- Values range from 0 to 10000.

## Examples

### Example 1

```text
Input: root = [5, 2, 8, 1, 3], k = 3
Output: 3
Explanation: The sorted values are 1, 2, 3, 5, 8.
```

### Example 2

```text
Input: root = [0], k = 1
Output: 0
Explanation: There is exactly one value.
```
