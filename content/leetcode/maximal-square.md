# Maximal Square

Find the largest square region containing only the character 1 in a binary matrix.
Return its area, not its side length.

## Examples

### Example 1

```text
Input: matrix = [["1", "1"], ["1", "1"]]
Output: 4
Explanation: The full two-by-two square has area 4.
```

### Example 2

```text
Input: matrix = [["1", "0"], ["0", "1"]]
Output: 1
Explanation: Only one-cell squares contain exclusively 1.
```

## Constraints

- 1 <= matrix.length, matrix[i].length <= 300
- The rectangular matrix contains only the characters 0 and 1.
