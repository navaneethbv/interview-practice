# Count of 2s

Count how many times the digit 2 appears when writing every integer from 0 to `n` inclusive.

## Examples

### Example 1

```text
Input: n = 25
Output: 9
Explanation: 2, 12, 20, 21, 22 (two 2s), 23, 24, and 25.
```

### Example 2

```text
Input: n = 1
Output: 0
```

## Constraints

- `0 <= n <= 10^9`
