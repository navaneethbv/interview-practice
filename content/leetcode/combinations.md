# Combinations

Return every selection of k distinct integers from 1 through n.
Each selection appears once; the order of selections and the order within a selection are unrestricted.

## Examples

```text
Input: n = 4, k = 2
Output: [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
Explanation: Choose every pair of different numbers.
```

```text
Input: n = 3, k = 1
Output: [[1],[2],[3]]
Explanation: Each one-number choice is a separate result.
```

## Constraints

- 1 <= n <= 20
- 1 <= k <= n
