# Reverse Words in a String

Reverse the order of words in s without reversing the characters inside a word.
Words are separated by spaces.
Return a string with exactly one space between words and no leading or trailing spaces.

## Examples

### Example 1

```text
Input: s = "  learn  by doing "
Output: "doing by learn"
Explanation: Trim the outer spaces and reverse the three words.
```

### Example 2

```text
Input: s = "hello"
Output: "hello"
Explanation: A single word is unchanged.
```

## Constraints

- 1 <= s.length <= 10000.
- s contains English letters, digits, and spaces, with at least one word.
