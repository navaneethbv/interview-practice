# To Lower Case

Replace every uppercase English letter in s with its lowercase version.
Preserve digits, punctuation, whitespace, and letters that are already lowercase.

## Examples

```text
Input: s = "Hello"
Output: "hello"
Explanation: Only the initial uppercase H changes.
```

```text
Input: s = "ALREADY 123!"
Output: "already 123!"
Explanation: Letters change while the space, digits, and punctuation stay the same.
```

## Constraints

- 1 <= s.length <= 100
- s contains printable ASCII characters.
