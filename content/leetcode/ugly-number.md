# Ugly Number

Return whether `n` is positive and every prime factor of n belongs to the set {2,3,5}.
The number 1 qualifies because it has no prime factors.

## Examples

### Example 1

```text
Input: n = 6
Output: true
Explanation: Its prime factors are 2 and 3.
```

### Example 2

```text
Input: n = 14
Output: false
Explanation: The prime factor 7 is not allowed.
```

## Constraints

- -2^31 <= n <= 2^31 - 1
