# Minimum Absolute Difference in BST

Return the smallest absolute difference between values of any two different nodes in the binary search tree.

## Examples

### Example 1

```text
Input: root = [4, 2, 6, 1, 3]
Output: 1
Explanation: Several neighboring sorted values differ by one.
```

### Example 2

```text
Input: root = [10, 4, 20]
Output: 6
Explanation: The closest pair is 4 and 10.
```

## Constraints

- The tree contains 2 through 10,000 nodes.
- 0 <= Node.val <= 100,000
- Node values are distinct.
