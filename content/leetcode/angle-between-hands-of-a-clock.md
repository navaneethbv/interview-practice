# Angle Between Hands of a Clock

Return the smaller angle in degrees between an analog clock's hour and minute hands.
The hour hand moves continuously as minutes pass.

## Constraints

- `1 <= hour <= 12`; `0 <= minutes <= 59`.

## Examples

### Example 1

```text
Input: hour = 3, minutes = 30
Output: 75.0
Explanation: The hour hand is at 105 degrees and the minute hand at 180.
```

### Example 2

```text
Input: hour = 12, minutes = 0
Output: 0.0
Explanation: Both hands point straight up.
```
