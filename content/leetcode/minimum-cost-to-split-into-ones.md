# Minimum Cost to Split into Ones

Begin with the integer n.
You may split any current integer x into positive integers a and b with a+b=x, paying a*b.
Return the minimum total cost to finish with n copies of 1.

## Examples

### Example 1

```text
Input: n = 5
Output: 10
Explanation: Splitting off one repeatedly costs 4+3+2+1.
```

### Example 2

```text
Input: n = 1
Output: 0
Explanation: No split is needed.
```

## Constraints

- 1 <= n <= 500
