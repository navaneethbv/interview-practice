# Palindrome Permutation

Return whether some rearrangement of all characters in s is a palindrome.
Character comparison is case sensitive; spaces and punctuation, if present, are ordinary characters.

## Constraints

- `1 <= s.length <= 5000`.
- s contains printable ASCII characters.

## Examples

### Example 1

```text
Input: s = "aabbc"
Output: true
Explanation: One rearrangement is abcba.
```

### Example 2

```text
Input: s = "abc"
Output: false
Explanation: Three odd character counts cannot form a palindrome.
```
