# Unique Binary Search Trees

Count the structurally different binary search trees that can be formed using every integer from 1 through n exactly once.
Each tree must satisfy the binary search tree ordering rule.

## Examples

### Example 1

```text
Input: n = 1
Output: 1
Explanation: There is only a root.
```

### Example 2

```text
Input: n = 3
Output: 5
Explanation: Choosing roots 1, 2, or 3 produces 2, 1, and 2 structures.
```

## Constraints

- 1 <= n <= 19.
