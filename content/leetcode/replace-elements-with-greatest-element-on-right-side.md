# Replace Elements with Greatest Element on Right Side

Replace each array entry with the largest value strictly to its right.
Replace the final entry with -1 and return the resulting array.

## Examples

### Example 1

```text
Input: arr = [6, 2, 9, 3]
Output: [9, 9, 3, -1]
Explanation: The largest later value for each of the first two positions is 9.
```

### Example 2

```text
Input: arr = [7]
Output: [-1]
Explanation: The only entry has no value to its right.
```

## Constraints

- 1 <= arr.length <= 10000
- 1 <= arr[i] <= 100000
