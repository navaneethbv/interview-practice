# Shortest Period With Over 20 Sales

Return the length of the shortest run of consecutive days with more than 20 total sales, or `-1` if there is none.

## Examples

### Example 1

```text
Input: sales = [5, 10, 15, 5, 10]
Output: 2
```

### Example 2

```text
Input: sales = [5, 5, 5, 5]
Output: -1
```

## Constraints

- `0 <= sales.length <= 10^5`
- `0 <= sales[i] <= 10^3`
