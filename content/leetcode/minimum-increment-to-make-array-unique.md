# Minimum Increment to Make Array Unique

One operation increments a chosen array entry by 1.
Return the fewest operations needed to make all entries distinct.

## Examples

### Example 1

```text
Input: nums = [1, 2, 2]
Output: 1
Explanation: Increase one 2 to 3.
```

### Example 2

```text
Input: nums = [3, 2, 1, 2, 1, 7]
Output: 6
Explanation: A minimum arrangement uses values 1,2,3,4,5,7.
```

## Constraints

- 1 <= nums.length <= 100,000
- 0 <= nums[i] <= 100,000
- The answer fits a signed 32-bit integer.
