# Middle of the Linked List

Return the middle node of a nonempty singly linked list.
If there are two middle nodes, return the second one.
The displayed result lists the values from the returned node through the tail.

## Examples

### Example 1

```text
Input: head = [1, 2, 3, 4, 5]
Output: [3, 4, 5]
Explanation: Node 3 is in the middle.
```

### Example 2

```text
Input: head = [1, 2, 3, 4]
Output: [3, 4]
Explanation: Choose the second middle node, at index 2.
```

## Constraints

- The list contains 1 through 100 nodes.
- 1 <= Node.val <= 100
