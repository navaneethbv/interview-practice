# Count Subarrays With All Remainders

Return how many subarrays contain at least one number of each remainder 0, 1, and 2 when divided by 3.

## Examples

### Example 1

```text
Input: arr = [1, 2, 3, 4, 5]
Output: 6
```

### Example 2

```text
Input: arr = [1, 3, 4, 6, 7, 9]
Output: 0
```

## Constraints

- `0 <= arr.length <= 10^5`
- `1 <= arr[i] <= 10^9`
